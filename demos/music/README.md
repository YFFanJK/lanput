# LANPUT 音乐厅：独立 HTML 设计提案

双击 `index.html` 打开总览，或分别打开下面的文件。每个 HTML 都内嵌 CSS、JavaScript、矢量装饰与交互，不需要服务器、安装依赖或访问外网；可以单独复制给其他人查看。

| 文件 | 方向 |
| --- | --- |
| 00-current.html | 当前音乐界面的布局与配色还原，方便对比 |
| 01-aurora.html | 极光流场：流动极光、微光粒子、大字沉浸歌词 |
| 02-vinyl.html | 黑胶星环：立体唱片、金色轨道、左右歌词排版 |
| 03-stage.html | 光束舞台：电影聚光、舞台倒影、中央歌词 |

四份演示都支持播放/暂停、时间轴拖动、全屏、动态氛围开关、歌词提前/延后、本地音频及 LRC 导入。空间不足时自动调整布局，遵循系统减少动态效果设置。

黑胶星环已进一步细化：中心标签与整张唱片同步旋转，唱臂固定，暂停保留旋转角度；播放区融入页面底部，包含细金色进度、悬停时间预览、居中播放控制与音量区。“上一句/下一句”按歌词时间轴定位。

默认使用 LANPUT 原创示例歌名与歌词，播放的是演示时间轴，**不会自动发声**。“歌词工具 → 选择本地音频”可播放你自己的音频，“导入 LRC 歌词”可加载对应时间轴。文件在本机读取，不上传服务器。背景粒子与流动为氛围装饰，不冒充频谱；导入本地音频后，线条幅度和粒子亮度会参考实际音频能量。

空格暂停/继续，左右方向键跳转 5 秒，F 全屏。当前版本还原页也使用同样的演示交互，方便在相同条件下对比，不直接连接原生投屏接收器。

黑胶星环方向已融合进 LANPUT 0.9.0 原生界面；此目录保留独立 HTML 参考与其他方案对比。重新生成命令：`python scripts/generate-music-demos.py`。
