# 0.3.0 沉浸影院验收

基线：用户已确认能播放的 0.2.3 与同一台电脑、手机、同一片源。保留旧版发布目录用于对照。

## 界面与接收

1. 运行 build-and-run.cmd 构建；顶栏和播放器应呈深色，不出现常驻设置侧栏。
2. 点击顶栏“开始接收”，沿用已保存网卡和名称；成功后手机 TV 列表能找到电脑。
3. 齿轮打开设置，接收中名称/网卡锁定；停止接收可修改并在下次启动保存。
4. 设置及诊断弹层在播放视频上方可见、可点击；点击外部或关闭按钮可收起。
5. 窗口边缘可缩放；标题栏可拖动、双击最大化；三个窗口按钮正常。
6. 100% / 125% / 150% / 200% DPI 检查最小窗口和最大化，面板不越界。

## 播放与快捷键

1. 从手机再次投放已验证片源，音画正常，手机播放、暂停、停止与进度控制正常。
2. 底部播放、暂停、停止、鼠标拖动进度、音量正常；方向键/分页键调整进度正常。
3. 空格播放/暂停；F / F11 进出全屏；Esc 返回。按钮、输入框、滑块的自身键盘交互不被抢占。
4. 全屏期间原生视频持续播放，浮动播放条和退出入口可见且可操作；返回后播放器与控制条恢复原位。
5. 从最大化窗口进入全屏再退出，应还原到最大化；从普通窗口退出应回到普通窗口。
6. Ctrl+O 或文件夹打开本地视频，正常播放；不在输入框编辑时误触快捷键。

## 失败与诊断

1. 模拟断网或使用不可播放片源时显示失败状态，应用不退出，仍能查看诊断/重试。
2. 信息按钮打开诊断，媒体检测输出实时更新；导出/日志目录可用。
3. 剪贴板占用时复制失败可重试或退回文件，窗口不退出。
4. 窗口最小化、恢复、休眠唤醒、显示器切换后，继续或重新投屏测试。
