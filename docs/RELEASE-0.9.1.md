# LANPUT 0.9.1 · 原生界面精修

> 这是一份历史版本记录，文中的服务器状态与交付路径仅代表当时环境。当前发布流程见 [RELEASING.md](RELEASING.md)。


保留深蓝暖金品牌、影院观众席、开映欢迎过渡和真实播放联动的黑胶旋转。外围界面收敛到安静、准确、温暖的方向。

## 已完成

- 间距：播放器边沿、音乐内容、控制区与弹层采用共同的间距节奏。
- 颜色：常用输入框和按钮采用较安静的边线；接收运行状态与暂停不再带出多组强调色，错误与连接中仍有明确语义。
- 图标：歌词入口使用与工具栏一致的细线箭头，带键盘焦点；歌词定位移入工具，使用明确的“上一句／下一句”文字，不再占用上一首／下一首的位置。
- 文案：精简重复英文装饰、常驻接收说明与日常播放／暂停 toast；保留“手机选好影片，投屏，剩下的交给LANPUT。”及开映欢迎语。
- 字体：进度时间与专辑信息统一为 12 DIP，音乐次要文字使用主题资源。
- 布局：歌曲元信息使用自动高度，唱片占用剩余空间，修复专辑行裁切；无专辑时收起该行。
- 控件：运行时停止接收和接收设置降为次要操作；需要开始接收、重试或恢复播放时才突出主操作。
- 视觉：保留影院与黑胶材质，音乐外框改用安静深色，减弱外围线条纹理。
- 动效：去掉金色按钮发光与悬停位移；保留轻微按压、真实播放旋转、开映与必要的连接过程反馈。
- 歌词：日常仅保留小型入口；搜索、候选、导入、来源和校准按需展开；无歌词、等待及失败原因仍可在主界面看到。

## 验证

原生验证使用本地测试音频与原创测试歌词，不代表已经重新完成手机端所有播放器的互通测试。覆盖最小窗口、普通窗口、最大化、全屏及还原时唱片、完整专辑信息、控制区边界；真实暂停恢复、动画关闭与最小化；鼠标进度点击及跨轮询拖动；歌词定位；音乐／视频／音乐切换；关闭退出。

测试记录：`tests-output/ui-polish-native-check.log`；协议回归与正式发布由 `scripts/package.ps1` 执行。

## 本地交付与在线发布

安装包：`dist/LANPUT-0.9.1-Setup-x64.exe`。

便携包：`dist/LANPUT-0.9.1-win-x64.zip`。解压后保留完整目录，再启动 LANPUT.exe。

项目根目录 `run.cmd` 直接启动此次更新后的 `dist/LANPUT-win-x64/LANPUT.exe`。

本次只生成本地安装包，未上传或修改服务器。需要发布时，将真实安装包上传后交给服务器助手执行：

```bash
lanput-publish.sh 0.9.1 /root/LANPUT-0.9.1-Setup-x64.exe "原生界面精修：修复专辑信息裁切，统一控件与状态层级，精简装饰和播放提示，歌词定位移入工具。"
```

更新地址继续使用 `https://fd.fansweb.top/lanput/updates/latest.json`；发布后应核对版本、真实下载及 `dist/SHA256SUMS.txt`。
