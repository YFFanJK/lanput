# 数据与网络行为

LANPUT 在所选局域网接口上提供发现及播放控制服务，并按控制端请求访问媒体来源。接收服务使用 TCP 41000、UDP 1900；媒体下载使用片源自身的地址和端口。

设置和日志保存在 `%LOCALAPPDATA%\LANPUT`，包括 `settings.json`、`desktop.json`、`updates.json` 和 `logs/`。这些文件不属于公开源码，不应上传仓库。卸载保留用户设置。

## 在线服务

- 在线匹配歌词时，将歌曲标题和歌手作为查询信息发送给 LRCLIB。可使用本地 LRC 替代在线匹配。
- 自动或手动检查更新时，请求已配置的 HTTPS 更新清单。官方默认地址位于 `installer/update-defaults.json`，已有用户配置优先。
- 诊断功能可以探测当前媒体的入口及部分资源链，以辅助定位访问失败；这与播放功能一样会连接媒体来源。

本项目未接入遥测或统计 SDK。公开源码中的服务地址是配置或依赖入口，不是账号凭据；维护分叉发行版时应配置自己的更新来源。

## 公开报告前

诊断代码对媒体 URL、签名参数和路径做脱敏处理，但截图、设备名称和用户自行添加的内容仍可能泄露个人信息。提交 Issue 前请人工检查，不要公开原始媒体地址、账号、密钥或私人日志。
