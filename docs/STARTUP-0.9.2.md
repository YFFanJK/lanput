# LANPUT 0.9.2 · 影院开幕

启动时，现有品牌 Logo 在深蓝幕布前淡入，随后先退场，再由幕布向两侧打开，露出原生影院观众席。

## 时序与行为

- 0–180 毫秒：Logo 淡入。
- 180–340 毫秒：短暂停留。
- 340–460 毫秒：Logo 淡出，避免与大厅内的文字叠加。
- 480–1160 毫秒：两侧幕布以缓入缓出打开。
- 每个应用实例只展示一次，从托盘恢复不会重播。
- 按 Esc、空格或 Enter，点击画面或跳过按钮均可立即结束；其他键盘操作先让出界面再正常处理。
- 收到媒体请求、调整窗口、最小化、隐藏窗口、关闭或关闭界面动画时，清理动画并立即让出界面。
- 关闭软件“界面动画”，或 Windows 关闭客户区动画时，直接显示主界面。

## 实现与性能

复用现有 Logo、品牌配色及影院场景。开场与自动接收并行，不等待网络，不添加人工加载进度或音效。

仅动画化透明度与缓存幕布的 RenderTransform，不改变真实 VideoView 或视频 HWND 的大小。使用初始属性值与关键帧，避免动画第一帧先显示终点。原生播放欢迎过渡和音乐厅沿用现有流程。

视觉层位于 VideoView.Content 内，与其独立 WPF 覆盖窗口处于同一绘制层，避免普通主窗口遮罩被视频窗口盖住。所有退出路径移除动画时钟，避免隐藏遮罩持续拦截输入。

## 验证与交付

`tests-output/StartupHarness` 验证原生 Logo 与幕布实际运动、自动结束、同实例不重复、自动接收并行、跳过按钮、Esc、关闭动画、收到媒体、缩放、最小化、播放中切换动画设置与关闭退出。用户桌面设置由测试程序备份并恢复。日志：`tests-output/startup-check.log`。

这不是手机端全播放器互通测试。正式打包脚本另运行已有协议与歌词回归。

安装包：`dist/LANPUT-0.9.2-Setup-x64.exe`。项目根目录 `run.cmd` 直接启动本次更新的程序。

本地打包不修改在线发布服务。上传真实安装包后，服务器助手可执行：

```bash
lanput-publish.sh 0.9.2 /root/LANPUT-0.9.2-Setup-x64.exe "新增可跳过的影院开幕动画，尊重系统动画设置，自动接收照常启动。"
```

设计流程使用 UI UX Pro Max。检索到的减少动态效果与适量动效规范适用；WPF 检索未找到适用的开场动画条目，原生动画实现采用项目已有 WPF 能力，没有将数据绑定转换器条目误用为动画指导。
