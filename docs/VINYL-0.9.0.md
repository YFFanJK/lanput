# LANPUT 0.9.0 原生黑胶星环

选定的 `demos/music/02-vinyl.html` 已融合进 WPF 原生音乐模式。音频轨道识别后自动进入黑胶音乐厅；有视频轨道的投放继续使用影院欢迎过渡。停止、结束或失败自动回到观众席。

## 画面与交互

- 深蓝、琥珀金背景，静态微光与星环；左侧唱片及曲目，右侧分层歌词。
- 整张唱片与中心 LANPUT 标签使用同一旋转变换，唱臂固定。暂停保留角度，继续从原角度旋转。
- 关闭界面动画、系统关闭动态效果、窗口最小化或隐藏时暂停装饰旋转；恢复后按真实播放状态决定是否继续。静态绘图冻结并缓存，不在动画中反复生成位图或调整视频 HWND 尺寸。
- 同一套真实播放控件随音乐模式移入画面底部，透明背景、圆形播放键、细金色进度及悬停时间。退出音乐模式后恢复视频布局。
- 上一句、下一句根据当前歌词时间轴跳转；没有有效时间轴或来源不支持 Seek 时禁用。按钮不代表手机播放队列的上一首、下一首。
- 歌词工具保留自动在线匹配、候选更换、本地 LRC、时间校准；展开时覆盖右侧局部，内容可滚动。

## 验证

核心协议、歌词及更新测试继续执行。原生验收覆盖 MP3 投放、LRC 导入、前后 Seek、暂停、切歌清理、停止/自然结束回厅、视频欢迎、音乐全屏及正常关闭。专项窗口验收检查最小尺寸、普通窗口、最大化、全屏及还原的控件边界；读取真实旋转角验证暂停、恢复、动画关闭和最小化；歌词按钮验证真实引擎时间。

正式更新地址继续为 https://fd.fansweb.top/lanput/updates/latest.json 。本地打包不自动上传服务器；发布 0.9.0 时请使用本批安装包及对应 SHA256。
