# LANPUT 0.5.0 · 用户方案融合说明

设计依据：用户提供的 LANPUT-Optimized-Frontend.html（琥珀金状态色版）。参考原文件随源码保存在 docs/design-reference/，保留用户内容，不替换为本次实现。

## 配色与结构

- 主背景 #0E1114，设置面板 #171B21，诊断面板 #14171D。
- 强调色 #E8C87A，主按钮文字 #2A2010；等待页标题、说明保持白色。
- 保留 1180×760 初始窗口、44/48/102/28 DIP 顶栏及控制区结构，以及小窗口精简布局。
- 保留固定尺寸窗口按钮、深色细滚动条、键盘焦点、长文本省略和提示。
- 输入边界与未播放轨道采用 #69717F，较 HTML 的装饰边界略亮，以保留可辨识的交互轮廓。

| 状态 | 颜色 | 触发依据 |
|---|---|---|
| 空闲 | #9BA1AB | 未接收、未播放 |
| 接收等待 | #F0B454 | 接收服务已开启 |
| 连接中 | #6CB6FF | 打开媒体、等待视频输出、网络恢复 |
| 播放 | #7EE2A8 | 引擎播放且有视频输出 |
| 暂停 | #9FA8D5 | 播放已暂停 |
| 错误 | #F27059 | 播放失败或接收启动/恢复失败 |
| 操作提示 | #8FA3BF | 复制、导出等信息提示 |

接收故障和单个影片失败保持区分：影片失败才显示影片重试横幅；接收服务故障不会伪装成影片错误。所有颜色同时配有状态文字。

## 动画

| 位置 | 实现 |
|---|---|
| 按钮 | 150 ms 轻移，按下 80 ms 轻压，松开 150 ms 恢复；标题栏三按钮保持固定 |
| 等待页 | 480 ms 淡入/14 DIP 位移，逐项间隔 70 ms |
| 等待页到画面 | 实际建立视频输出后 480 ms 淡出 |
| 设置与诊断 | 打开 320 ms 淡入/14 DIP 位移；关闭按钮 180 ms 淡出 |
| 暂停 | 视频叠层淡入暂停图标与轻遮罩，150 ms |
| 连接提示 | 连接阶段双环扩散；接收/连接/播放状态点轻脉冲 |
| 操作提示 | 280 ms 淡入，约 2.4 秒后淡出 |
| 全屏播放台 | 隐藏和恢复各 180 ms，继续沿用三秒无操作规则 |

直接点击弹窗外部、Esc 或系统强制关闭时即时收起，确保系统焦点和窗口生命周期正常。新的动画替换同属性旧动画，不排队；完成后移除动画时钟，最小化、隐藏、退出时停止持续动效。

设置增加“界面动画”，保存到 desktop.json。既有文件未包含此项时默认开启；同时遵循 Windows 的客户端动画设置。系统减少动态效果或手动关闭后，功能与状态提示仍即时可用。

## WPF / VLC 适配

- 使用现有 VideoView.Content 叠层放置等待页、暂停提示、操作提示与全屏播放条，保留已有视频宿主。
- HTML 的 backdrop-filter 不直接映射到原生 VLC 视频；暂停采用半透明遮罩，不给视频施加模糊。
- 等待页保留微弱琥珀背景层次；播放画面不叠加持续呼吸光效，以免改变影片观感。
- 全部是 WPF 原生动画，不引入网页运行时或新 NuGet 依赖。
- 动画实现以用户 HTML 和通用可访问性原则为依据；本地技能库没有匹配的 WPF 动画专项条目。

## Windows 验收

1. 检查 100%/125%/150%/200% DPI，以及 900×540 最小窗口，错误横幅、控制条和设置末尾选项可见。
2. 真实投放、暂停、继续、停止、失败与重试；颜色和文案跟随状态，确认有视频输出后再撤等待页。
3. 连续快速打开/关闭两个弹窗、点击外部和 Esc；没有透明的不可操作面板，焦点正常返回。
4. 全屏自动隐藏后移动鼠标、拖动进度、使用键盘；控制条平滑恢复并可操作。
5. 在设置中关闭动画、重新打开；Windows 关闭动画时也应即时显示，无残留脉冲。
6. 最小化、退到托盘、恢复、退出；不留后台装饰动画，不影响音量、防熄屏和接收恢复。
7. 复制和导出诊断；确认提示与实际操作结果一致。
