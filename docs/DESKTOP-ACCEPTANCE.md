# LANPUT 0.4.1 六项功能验收

此版本保留原 HTTP User-Agent 和 SSDP Server 兼容标识。不要同时运行旧 LanCast：新版本单实例只管理 LANPUT 自身。

| 功能 | 行为 | Windows 验收步骤 |
|---|---|---|
| 防熄屏 | 默认开启；正常播放时保持显示与系统唤醒，暂停/停止/失败/退出时释放，可在设置关闭 | 临时将系统屏幕超时设为短时，播放超过该时长；暂停后确认按系统策略熄屏。可用 `powercfg /requests` 对比。不会阻止用户主动休眠、合盖或强制关机 |
| 单实例 | 同一 Windows 会话只运行一个 LANPUT；再次打开会显示并激活已有窗口，包括托盘和最小化状态 | 连续双击 exe，任务管理器确认只有一个实例；收起至托盘后再启动；异常结束后重新打开 |
| 网络恢复 | 每 5 秒兜底检查，地址变化防抖 2 秒；唤醒后重建服务。优先原网卡原 IP，再选同名网卡唯一 IP；不自动切 VPN/其他网卡 | 接收中关闭 Wi-Fi 再开启；换路由器/DHCP 地址；休眠后恢复；等待时点击停止，确认不再自动恢复。UDN 不变，必要时手机重新投放，不承诺断网影片无缝续播 |
| 日志轮转 | 每文件约 1 MiB，最多 3 个备份；启动时清理超过 14 天或历史总量超过 32 MiB 的匹配日志；搜索日志 5 秒聚合 | 长时间搜索设备，确认界面不会刷满；检查 receiver/application 文件轮转。导出的诊断和其他文件不在自动清理范围；活跃会话会在清理后继续增长到各自轮转上限 |
| 全屏自动收起 | 正常视频播放且无操作 3 秒后收起控制条与退出按钮；鼠标/键盘唤回。暂停、错误、拖动、鼠标停在控制条和面板打开时保留 | 手机或本机播放后全屏，移开鼠标等待；移动鼠标、空格、Esc；拖动进度时不收起；有键盘焦点的控件收起时焦点移至视频覆盖层 |
| 托盘与记忆 | 托盘菜单可显示、播放/暂停、开始/停止接收和退出；关闭到托盘默认关闭，需主动勾选。正常关闭记忆窗口几何、最大化状态与音量；音量稳定 2 秒自动保存 | 菜单“收起到托盘”、双击图标恢复；勾选关闭到托盘后点 X；通过托盘退出；重新启动确认窗口和音量；拔掉外屏后窗口应校正到虚拟桌面范围 |

## 构建与回归

在 Windows 解压源码后运行 `build-and-run.cmd`。脚本先运行 Core 测试，再发布自带运行时的 x64 文件夹和版本化 ZIP。

新增 Core 回归用例覆盖：恢复时不选其他网卡/歧义 IP、日志轮转上限、旧日志清理、保留无关文件、不可写日志不抛出到调用方。

本次 Linux 执行环境没有 .NET SDK，因此 C# 测试、WPF 编译和上述 Windows 行为尚未运行；结构检查不能替代它们。还需回归已成功的手机片源、本地 MP4、暂停、进度、音量、全屏和诊断。
