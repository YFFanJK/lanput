# LANPUT 0.9.3 · 放慢开幕节奏

用户反馈 0.9.2 的开场太快，本次保留原生影院开幕方案，将总时长从 1.16 秒调整为 3.2 秒。

| 阶段 | 时间 | 表现 |
| --- | --- | --- |
| 品牌入场 | 0–0.42 秒 | Logo 逐渐浮现 |
| 品牌停留 | 0.42–1.30 秒 | 留出完整观看 Logo 的时间 |
| 品牌退场 | 1.30–1.65 秒 | 平稳淡出，避免与大厅内容重叠 |
| 开幕前停顿 | 1.65–1.70 秒 | 留出短暂呼吸 |
| 幕布打开 | 1.70–3.20 秒 | 保留缓入缓出，以 1.5 秒展开观众席 |

可跳过、收到媒体立即让出画面、尊重系统和软件动画设置、后台自动接收、从托盘恢复不重播等行为沿用 0.9.2。动画仍只调整透明度与缓存幕布位移，不改变视频窗口大小。

时间节点集中为代码常量。原生预览工具读取同一组常量，避免演示与实际软件节奏不一致。

验证日志：`tests-output/startup-0.9.3-check.log`；打包与协议回归：`tests-output/startup-0.9.3-package.log`。原生动画预览为逐帧导出，覆盖完整开幕及完成后的大厅。

安装包：`dist/LANPUT-0.9.3-Setup-x64.exe`。项目根目录 `run.cmd` 可直接启动更新后的程序。

需要更新服务器时，上传真实安装包后由服务器助手执行：

```bash
lanput-publish.sh 0.9.3 /root/LANPUT-0.9.3-Setup-x64.exe "优化影院开幕节奏：Logo 停留更充分，幕布缓缓展开，保留跳过与投屏立即接管。"
```
