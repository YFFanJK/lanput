# LANPUT 0.8.0 私人音乐厅

实际存在音频轨道且没有视频轨道时，自动显示音乐厅。视频暂时没有画面不会触发音乐模式。有视频的投放仍使用“好戏马上上演”的影院过渡；停止、自然结束或失败返回观众席。

显示歌名、歌手、专辑与逐行歌词，使用深蓝与琥珀金渐变背景。歌词跟随播放器真实时间，暂停、手机 Seek 和拖动进度均同步；关闭动画或系统动态效果时直接切换。第一版没有逐字卡拉 OK、声音识别或自动生成歌词。

## 在线歌词

通过 LRCLIB 搜索歌名与可用的歌手。每个查询在进程内缓存，最多保留 32 项；请求串行、限频并遵循 Retry-After，不做失败自动重试。断网、超时和无匹配不影响音频播放。

0.8.1 起，只要搜到可用歌词便自动应用：优先精确录音匹配，否则按歌名、歌手、时长、专辑与同步歌词可用性排序。歌手缺失、时长有偏差或结果不唯一也无需确认。自动选择不保证版本完全准确，可手动更换。展开“歌词工具”可修改歌名和歌手，搜索并选择候选，点击“使用此版本”。纯音乐只有在服务明确标记 instrumental 时显示；没有歌词不代表纯音乐。

有时间轴则逐行高亮；仅有文本歌词时显示可滚动文本并标明没有时间轴。搜索向 https://lrclib.net 发送歌名、歌手，不发送媒体 URL 或投屏链接。接口文档：https://lrclib.net/docs 。目前以应用名及版本标识；项目有正式主页或联系邮箱后，应按服务方要求补充客户端联系信息。歌词覆盖率与版本准确性取决于上游资料。

## 本地歌词

“歌词工具 → 导入 LRC”支持 UTF-8、带 BOM 的 UTF-16 和常见 GBK 编码，最多 1 MB。支持多时间标签、小数时间与 offset。“提前/延后 0.5 秒”用于校准，最多正负 60 秒，正值使歌词更早出现。导入只作用于当前播放源，切歌清空。

## 验证范围

核心测试覆盖 DIDL 命名空间、匿名歌手与 DTD 拒绝；LRC 多标签、时间精度、offset、空行、前后定位；误匹配与多版本拒绝；在线缓存与 Retry-After。

原生验收使用合成 MP3 和原创 LRC，检查音乐自动切换、导入、前后 Seek、暂停、切歌、停止、视频影院过渡与视频转音乐。不同手机软件的元数据完整度需在实际投放中继续确认。
