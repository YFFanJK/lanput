# LANPUT 0.9.0 界面审查

实施状态：用户已确认“按此方向精修原生界面”。本报告保留审查时的判断，实际完成项与验证见 [0.9.1 发布说明](RELEASE-0.9.1.md)。

范围：检查现有原生 WPF 影院、音乐界面截图及其布局、主题、动效代码。本轮不修改生产代码。截图来自项目已有的原生界面采集，没有重新启动应用；设置与诊断弹层仅检查代码，未进行新的交互验证。

## 判断

采用精修模式。影院观众席、开映过渡、黑胶唱片与深蓝金色已经形成产品身份，应保留。成熟感不足主要来自界面外框、状态与工具层不断累加，缺少统一的密度、语义和视觉层级。不建议重新套一个流行模板。

## 五行设计方向

- 产品：让手机上的电影和音乐，在 Windows 电脑上得到专注的播放体验。
- 性格：安静、准确、温暖。
- 世界：夜间放映室与实体唱机；外围采用现有深色中性色，保留深蓝与暖金品牌。
- 重点：影院开映，以及黑胶与当前歌词；材质与细节集中在这两处。
- 签名：暖金始终指向当前播放焦点，外围控件退到次要层级。

## 建议实施顺序（尚未实施）

1. 先修元信息裁切与歌词定位按钮语义，保住基本体验。
2. 按间距、颜色、图标、文案、字体、布局、控件细节、视觉、动效的顺序精修；保持现有主布局、功能及品牌。
3. 对照现有影院与音乐截图验证；补看空闲、播放、暂停、无歌词、工具展开及短窗口状态，检查 DPI 与键盘操作。

按照本次调用的 unslop 技能要求，审查与方向需先交用户选择后再编辑界面。本报告不是已完成的界面修改，也不声称已重新验证运行时表现。
